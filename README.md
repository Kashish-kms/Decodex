# 🚀 Decodex - AI Code Generator

Generate code using AI with support for 12+ programming languages.

## Features

✨ **AI-Powered Code Generation** - Uses Google Gemma 4 31B model
🔤 **12+ Languages** - Python, JavaScript, Java, C++, Go, Rust, etc.
⚡ **Fast & Free** - Powered by OpenRouter
🎨 **Beautiful UI** - Dark theme with syntax highlighting
📋 **Copy to Clipboard** - Easy code sharing

## Tech Stack

**Frontend:**
- React 18
- Vite
- Axios

**Backend:**
- Node.js
- Express
- OpenRouter API

## Local Setup

### Prerequisites
- Node.js v18+
- npm or yarn

### Backend Setup

```bash
cd backend
npm install
cp .env.example .env
# Edit .env and add your OpenRouter API key
npm run dev
